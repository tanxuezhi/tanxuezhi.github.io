# Xuezhi Tan Academic Website

Static academic website coordinated with the public SYSU profile: <https://civil.sysu.edu.cn/teacher/482>.

## Publish with GitHub Pages

1. Create an empty GitHub repository, for example `xuezhi-tan.github.io` (user site) or `academic-website` (project site).
2. Copy this folder's contents into that repository and push them to the `main` branch.
3. In the GitHub repository, open **Settings → Pages**, select **GitHub Actions** as the source.
4. The included workflow publishes automatically after the first push. A user site will be served at `https://<github-user>.github.io/`; a project site at `https://<github-user>.github.io/<repository>/`.

No build tool or server is required. Edit `index.html`, `styles.css`, or `script.js`, commit and push to publish updates.
